📊 MayurStationery Sales Dashboard

An interactive MayurStationery Sales Dashboard developed using Tableau to analyze sales performance, profit, quantity, product performance, and sales trends.

🎯 Project Objective

The objective of this project is to transform MayurStationery sales data into an interactive Tableau dashboard that provides meaningful insights through data visualization.

🛠️ Tools & Technologies

* Tableau Desktop / Tableau Public
* Microsoft Excel / CSV
* Data Visualization
* Dashboarding

📈 Dashboard Features

* Total Sales KPI
* Total Profit KPI
* Total Quantity KPI
* Sales Trend over Time
* Category-wise Sales
* Top 10 Products by Sales
* Regional/Location-wise Sales
* Interactive Filters
* Calculated Fields

🧮 Calculated Fields

* **Total Sales** = `SUM([Sales])`
* **Total Profit** = `SUM([Profit])`
* **Profit Ratio** = `SUM([Profit]) / SUM([Sales])`
* **Average Sales** = `AVG([Sales])`

🔍 Key Insights

1. The dashboard provides an overview of total sales, profit, and quantity.
2. Sales trends can be analyzed over different time periods.
3. Category-wise analysis helps compare the performance of stationery categories.
4. The Top 10 Products visualization highlights products with the highest sales.
5. Regional analysis helps identify variations in sales across different locations.
